# Portfolio Decision Log

## D-001 — Synthetic-only demo

**Decision:** Use the checked-in synthetic golden dataset and corpus for the reviewer
demo. **Reason:** authorization and data-use boundaries make confidential enterprise
content out of scope for this portfolio stage. **Consequence:** the demo proves
reproducibility and safety contracts, not enterprise-domain coverage.

## D-002 — Single-agent remains default

**Decision:** Keep Stage 14 single-agent as the default. **Reason:** Stage 19's
multi-agent route is an evaluation-only candidate and lacks the required powered,
independently verified evidence of benefit. **Consequence:** no multi-agent quality
claim is published.

## D-003 — Artifact-first metrics

**Decision:** Publish only metrics bound to checked-in, versioned artifacts. **Reason:**
numbers copied from terminal output cannot be independently traced or reproduced.
**Consequence:** unavailable human quality, provider cost, and production SLO values
remain explicitly unavailable.

## D-004 — No invented license

**Decision:** Do not add a license file without an owner-approved legal choice.
**Reason:** choosing a default license is a legal/product decision, not a technical
assumption. **Consequence:** this repository remains “all rights reserved / license
decision required” unless the owner later supplies a license choice.

## D-005 — Walkthrough plan, not a fake recording

**Decision:** Include a repeatable walkthrough script and placeholder status only.
**Reason:** no recording was supplied or produced. **Consequence:** reviewers can
recreate the walkthrough while the recording deliverable remains openly pending.
